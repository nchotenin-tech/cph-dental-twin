ปลายทางที่รับปรึกษามากที่สุด

นับ case ตามรหัส case ไม่ซ้ำ ส่วนเส้นบนแผนที่นับแถวละหนึ่งสาขา (case เดียวที่ปรึกษาหลายสาขาจะมีหลายเส้น) ประเภทโรงพยาบาลและแม่ข่าย (Node) ตามทะเบียน hoscpho พิกัดโรงพยาบาลจาก OpenStreetMap (ซับใหญ่ หนองบัวระเหว เกษตรสมบูรณ์ เทพสถิต ใช้ที่ตั้งตัวอำเภอ ส่วน สสจ. วางเยื้องจากตัวเมืองเพื่อไม่ให้ทับ รพศ.) ขอบเขตอำเภอจาก OpenGISData-Thailand ภาพภูมิประเทศสร้างจากข้อมูลความสูง AWS Terrain Tiles (SRTM และแหล่งเปิดอื่น) ความละเอียดราว 500 ม.

ยังไม่มีข้อมูลการปรึกษา

นำเข้าไฟล์ .csv ที่ export จาก CPH Consult เพื่อแสดงเส้นปรึกษาบนแผนที่ ไฟล์อ่านและจำไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น เปิดหน้านี้ครั้งต่อไปข้อมูลล่าสุดจะแสดงทันที

ไฟล์ที่นำเข้าได้

ไฟล์อ่านในเบราว์เซอร์ของผู้เปิดเท่านั้น ไม่ถูกอัปโหลดไปที่ใด หน้านี้จำไฟล์ล่าสุดไว้ในเบราว์เซอร์เครื่องนี้ กด "ล้างข้อมูล" เพื่อลบ

1. ไฟล์ export จาก CPH Consult (แนะนำ)

เลือกไฟล์ .csv ที่ส่งออกจากหน้า Digital Twin ของ CPH Consult ได้ทันที ระบบอ่านคอลัมน์เหล่านี้

case_idรหัส case ใช้นับจำนวน case ไม่ซ้ำ
origin_hospital_name / _levelต้นทาง และระดับ (รพช. / รพ.node / รพศ. / สสจ.) ใช้กำหนดว่าเป็นแม่ข่ายหรือลูกข่าย
destination_hospital_name / _levelปลายทาง
specialtyสาขาทันตกรรม หนึ่งแถวต่อหนึ่งสาขา
workflow_typeconsult / refer / shared_care
status_bucket, status_label_thกลุ่มสถานะและชื่อภาษาไทย ถ้ามีสถานะใหม่จะแสดงตามชื่อในไฟล์
sent_at, last_activity_atเวลาส่ง และเวลากิจกรรมล่าสุด (UTC)
snapshot_atเวลาที่ export ใช้คำนวณอายุ case
